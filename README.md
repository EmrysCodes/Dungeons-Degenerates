# Dungeons & Degenerates

Humorous fantasy party card game — absurd scenarios, ridiculous actions, rotating judge, Loot Tokens.

## Play the web demo

```bash
cd web
npm install
npm run dev
```

See [`web/README.md`](web/README.md) for rules and stack notes.

The original Godot/Xogot prototype and card art live at the repo root (`GameScene.gd`, `assets/cards/`).
